# Facebook 貼文典藏

將 Facebook 匯出的貼文與圖片整理成可搜尋的離線典藏。可以用內文或相片說明找回貼文、按年份篩選，並從貼文直接開啟圖片。資料在瀏覽器本機處理。

## 使用方式

1. 直接用瀏覽器開啟本專案最外層的 `index.html`。
2. 在 Facebook 設定裡選擇要保存的個人檔案，將資料匯出到裝置。建議選 JSON、所有時間與高畫質。想保留社團貼文時也要包含相應資料類別。[Facebook 官方匯出說明](https://www.facebook.com/help/212802592074644)
3. 按「選擇 ZIP 分檔」，一次選取同一次匯出的全部分檔。已解壓縮的資料可用「選擇已解壓資料夾」開啟。
4. 輸入關鍵字搜尋，或選取年份。點選圖片可看大圖。打開「匯入核對報告」查看缺少的附件、只有連結的圖片，以及未能配對的項目。
5. 按「儲存離線典藏 ZIP」。將產出的 ZIP 完整解壓後，開啟裡面的 `index.html`，就能再次查閱。保留 Facebook 原始 ZIP，可供日後核對。

典藏範圍取決於實際匯出的內容。完全缺席的貼文或附件無法由核對報告推算。
