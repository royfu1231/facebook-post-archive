# Facebook 貼文典藏

[English](README.en.md)

將 Facebook 匯出的貼文與圖片整理成離線典藏，畫面仿照 Facebook 個人檔案：封面、大頭貼、簡介、貼文、相片、朋友。資料在瀏覽器本機處理。

## 使用方式

1. 直接用瀏覽器開啟本專案最外層的 `index.html`。
2. 在 Facebook 設定裡選擇要保存的個人檔案，將資料匯出到裝置。建議選 JSON、所有時間與高畫質。想保留社團貼文時也要包含相應資料類別。個人檔案的簡介和朋友需要「個人資料」和「朋友」類別。[Facebook 官方匯出說明](https://www.facebook.com/help/212802592074644)
3. 按「選擇 ZIP 分檔」，一次選取同一次匯出的全部分檔。已解壓縮的資料可用「選擇已解壓資料夾」開啟。
4. 在「貼文」按「篩選」可搜尋關鍵字、選年份。「相片」分頁有所有相片、相簿和影片。點選圖片可看大圖，用左右鍵切換。按「匯入核對報告」查看缺少的附件、只有連結的圖片，以及未能配對的項目。
5. 按「儲存離線典藏 ZIP」。將產出的 ZIP 完整解壓後，開啟裡面的 `index.html`，就能再次查閱。保留 Facebook 原始 ZIP，可供日後核對。

你寫的留言和你按的心情在「活動紀錄」，依日期排列。Facebook 匯出檔只有你自己的留言和心情，沒有別人在你貼文按的心情和留言，所以貼文下方不顯示互動數字。

介面語言跟著瀏覽器設定（繁體中文或英文），也可以用右上角的語言選單切換，選擇會記在這台瀏覽器。Facebook 寫進匯出檔的文字，例如貼文標題和相簿名稱，照原樣顯示。

典藏範圍取決於實際匯出的內容。完全缺席的貼文或附件無法由核對報告推算。

## 版本紀錄

### 0.3.0

- 同時開啟多份匯出時，朋友名單會合併，重複的朋友只列一次。
- 程式碼精簡，功能不變。

### 0.2.0

- 畫面改成 Facebook 個人檔案的樣子：封面、大頭貼、簡介、貼文、相片、朋友和活動紀錄。
- 介面可切換繁體中文和英文。
- 修正：
  - 核對報告的心情數量與活動紀錄一致，同一個心情不再重複計算。
  - 「誰可以看到」的分享對象設定不再被當成心情紀錄。
  - 朋友名單分成多個檔案時，全部都會讀取。
  - 另開一份匯出時，朋友和活動紀錄的搜尋會清空。
  - 名字裡有「在」或「和」時不會被截斷。
  - 找不到姓名時，貼文作者不再重複顯示。
  - 分享的動態回顧不再顯示「匯出檔未提供原文」。
  - 匯入或儲存期間無法切換語言。
  - 減少記憶體用量，相片分頁開得更快。

### 0.1.0

- 第一個測試版。
